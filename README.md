# Screener Robots — роботы и алгоритмы на всех крипто-фьючерсах

Десктопный скринер детекции торговых роботов на USDT-фьючерсах **всех** инструментов
четырёх бирж: **Binance, MEXC, Bitget, Gate** (~3700 символов). Вдохновлён Plutos
(moex.plutos.finance) с переносом логики на крипторынок.

## Архитектура «радар → глубокий анализ»

```
все фьючерсы (3700) ──► РАДАР (O(1)/сделка)          пул ≤ 200 ──► ПОЛНЫЕ ДЕТЕКТОРЫ
                        метроном-сниффер               промоушен:    таймер-роботы (такт/сила)
                        сделка ≥ 12× типичного         score ≥ 80    фликер / спуфинг / айсберги
                        всплеск частоты                или 2 метронома / 3 мин       │
                        │                                            ▲               │
                        └────────── авто-промоушен ◄─────────────────┘    демоушн через 10 мин тишины
```

- **Радар** покрывает весь рынок: EMA-типичный размер (q25 по окну 200), метроном-сниффер
  (7 сделок одного размера, интервалы ±10%), всплески частоты — всё с кулдаунами против шума
- **Пул** — символы с полными детекторами; топ-15 по обороту каждой биржи держится постоянно
- Детекция роботов: такт (модальный интервал, ±15%, ≥5 принтов), сила, направление,
  «двигал рынок или шёл за ним», score 0–100

## Индикатор BID ASK

Нулевая отметка по центру; сделка = вертикальная линия от нуля (покупка вверх, продажа вниз,
длина = объём). Удары роботов — яркие зелёные/красные, рынок — приглушённый.
- Лента уходит влево, **история 24 часа** сохраняется на диске (SQLite `history.db`)
- После перезапуска история восстанавливается; офлайн-периоды добираются REST-архивами
  бирж (Binance aggTrades, Gate futures.trades) с флагами роботов (fast-forward детектор)
- Прокрутка истории: драг; зум: колесо (время), Shift+колесо (амплитуда); 2×клик — LIVE
- Пиксельная агрегация: на сильном отдалении сделки схлопываются в композитные бары —
  без пустот; несобираемые офлайн-диапазоны (Bitget/MEXC) помечены штриховкой

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Настройка — config.yaml

```yaml
monitor:
  mode: all              # all = все фьючерсы (радар), top = топ по обороту
  top_n: 15              # топ-символов в пуле постоянно
  pool_max: 200
  demote_after_min: 10
  radar_threshold: 50
detector:                # роботы-таймеры
  size_k: 3.0
  min_prints: 5
  tick_tolerance: 0.15
  min_regularity: 0.6
history:
  retention_h: 24
  auto_record_robots: true   # авто-запись 24ч истории символов с роботами
alerts: {enabled: true, sound: true}
```

## Производительность (замерено)
- 3700 символов, ~2900 активных: CPU ~10% одного ядра, ~25 WS-соединений
- Лимиты подписок: Binance 190/conn, MEXC 150/conn, Bitget 100/conn, Gate 250/conn
- History: батч-запись 1 с, retention 24 ч, WAL

## Ограничения
- Биржи не отдают L3 — идентификация роботов поведенческая
- Архив сделок: только Binance и Gate; офлайн-периоды Bitget/MEXC не восстанавливаются
- Стакан (фликер/спуфинг/айсберги) считается для пула/выбранного символа, не для всех 3700
- Для сверхликвидов бэктфил глубже ~1.5 млн сделок обрезается бюджетом запросов
